# 마크다운 문법

마크다운은 문법이 쉽고, 간편하게 관리할 수 있으며, 다양한 플랫폼과 프로그램에서 지원됩니다.

마크다운에는 이런 문법들이 있습니다.

1. 제목
   제목은 #으로 시작하며 최대 6개까지 붙일 수 있습니다.

예문

# 제목 1

## 제목 2

### 제목 3

#### 제목 4

##### 제목 5

###### 제목 6

2. 강조
   기울이기: \*혹은\_로 감싼 텍스트
   굵게: \*\*혹은\_\_로 감싼 텍스트
   취소선: ~~로 감싼 텍스트

예문
_기울이기_ _기울이기_
**두껍게** **두껍게**
~~취소선~~
**_혼용해서 기울이고 두껍게 사용할 수 있습니다._**

3. 인용
   > 으로 시작하는 텍스트로 최대 3개까지 사용 가능합니다.

예문

> 인용
>
> > 인용문
> >
> > > 인용하다

4. 목록

순서가 없는 목록은 \*, +, - 를 이용해서 만들 수 있습니다.
숫자를 기입하면 순서가 있는 목록이 됩니다. 리스트 안 리스트를 사용하려면 tab과 함께 1번부터 나열해서 작성해야 합니다.

예문
*하나
*둘 \*셋 +하나 +둘 +셋 -하나 -둘 -셋

1순서
1있는
1목록
1TAB
1순서
1있는
1목록

5. 링크
   링크는 다음과 같이 표현할 수 있습니다.
   [이름](링크) [이름](링크"설명") [이름][참조] [참조]: 링크 [참조]: 링크"설명"

예문
[네이버](https://www.naver.com/)
[구글](https://www.google.com/"구글 홈페이지")
[깃허브][git]
[git]: https://github.com/
[유튜브]: https://www.youtube.com/ "수많은 영상이 있는 유튜브"

7. 인라인
   `로 감싸 인라인 코드를 표현할 수 있습니다.

예문
`touch`로 필요한 파일을 만들 수 있습니다.

8. 블록
   `를 3번 이상 입력하고 그 안에 명시하여 코드 블록을 표현할 수 있습니다. 시작 개수와 종료 개수가 같아야 합니다.

예문

```
git add .
git commit -m "커밋하기 예문"
```

9. 특수문자 표현하기
   특수문자를 표현할 땐 표시할 문자 앞에\를 넣고 작성하면 됩니다.

예문
\` \* \- \+

10. 표
    표를 표현합니다.
    테이블 헤더를 구분하기 위해, 3개 이상의 - 기호를 사용합니다.
    테이블 헤더를 구분하며 : 기호와 - 기호를 추가해 칸 안의 내용을 정렬할 수 있습니다.
    :--- 좌측 정렬
    :---: 가운데 정렬
    ---: 우측 정렬

예문
| 제목 | 내용 | 비고 |
| :--- | :---: | ---: |
| 멋쟁이사자처럼 | 마크다운 | 과제하는 중 |

11. 체크리스트
    순서가 없는 목록에서 사용되는 -,\*,+ 뒤에 []를 사용하여 체크리스트를 만들 수 있습니다.

예문

- [x] 수업 참여를 위해 8시 50분까지 컴퓨터 앞에 착석하기
- [] 멋쟁이사자 프론트엔드 17기 수료하기

12. 수평선
    ---, \_\_\_, \*\*\* 이 기호들을 3번 이상 입력하여 수평선을 표시할 수 있습니다.

13. 줄바꿈
    줄바꿈을 하려면 \<br>를 사용하거나 문장 끝에 스페이스를 2번 이상하고 엔터를 입력합니다.

예문
마크다운에서는 문장 끝 뒤에 스페이스 바 2번 입력으로 줄을 바꿀 수 있구나.  
조사하면서 보니 줄바꿈으로 `\<br>`태그를 사용하는 걸 추천하더라 <br>
